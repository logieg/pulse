# Pulse
Procedural Music Sequencer 🎶

Pulse is a frontend-only minimalist music sequencer that uses the Web Audio API to procedurally generate sounds.

Preact + TypeScript + Vite + Tailwind CSS

## Getting Started

Setup:  
```bash
npm install
```

Dev server (hot reloading):  
```bash
npm run dev
```

Prod server (static):  
```bash
npm run build
npm run preview
```
